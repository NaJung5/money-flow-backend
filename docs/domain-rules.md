# Money Flow 도메인 규칙

## 공통 규칙

- 모든 Entity는 생성일시와 수정일시를 가진다.
- 소프트 삭제를 사용하며 삭제 시 `deletedAt`을 기록한다.
- 삭제된 데이터는 일반 조회 대상에서 제외한다.
- 시간 기준은 `Asia/Seoul`이다.

## Transaction

### 필드

- type: 거래 유형
- amount: 금액
- transactionDate: 거래일
- category: 카테고리
- memo: 메모
- place: 거래 장소

### 생성 규칙

- 거래 유형은 필수이다.
- 금액은 필수이며 0보다 커야 한다.
- 거래일은 필수이다.
- 카테고리는 필수이다.
- 거래 유형과 카테고리 유형이 일치해야 한다.
- 비활성화되거나 삭제된 카테고리는 사용할 수 없다.
- 하위 카테고리만 거래에 사용할 수 있다.
- 메모는 50자 이하이다.
- 거래 장소는 선택이며 50자 이하이다.

### 수정 규칙

- 거래 유형은 변경할 수 없다.
- 금액, 거래일, 카테고리, 메모, 거래 장소를 변경할 수 있다.
- 변경할 카테고리도 생성 시점과 동일한 규칙을 만족해야 한다.

### 삭제 규칙

- 실제 데이터를 삭제하지 않고 `deletedAt`을 기록한다.

## Category

### 생성 규칙

- 이름은 필수이며 50자 이하이다.
- 거래 유형은 필수이다.
- 카테고리 유형은 필수이다.
- 생성 시 활성 상태이다.
- 상위 카테고리와 하위 카테고리의 거래 유형이 같아야 한다.

### 수정 규칙

- 시스템 카테고리는 수정할 수 없다.
- 사용자 카테고리만 이름을 변경할 수 있다.
- 상위 카테고리는 생성 후 변경할 수 있다.
- 삭제된 카테고리는 수정하거나 활성화 상태를 변경할 수 없다.

### 활성화 규칙

- 활성화 및 비활성화가 가능하다.
- 비활성 카테고리는 신규 거래에 사용할 수 없다.
- 기존 거래의 카테고리가 비활성화되면 해당 거래를 최상위 카테고리로 변경한다.

### 삭제 규칙

- 시스템 카테고리는 삭제할 수 없다.
- 사용자 카테고리는 소프트 삭제한다.

## Money

- 정수 금액만 사용한다.
- 금액은 0보다 커야 한다.
- 0 이하이면 `IllegalArgumentException`이 발생한다.
